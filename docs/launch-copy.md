An agent skill that turns saved videos and articles into in-depth, illustrated HTML reading guides with source references. Bilibili-first validation.

## 简短介绍

收藏了很多视频，回头却只记得标题？

我做了 MarkKiller「收藏夹杀手」，把收藏夹里的视频，或指定的视频和图文，整理成真正能读进去的深度解读：先看封面和重点，再通过整体讲解、逻辑图、实例与原作画面理解过程，最后回查来源、判断怎样借鉴。

输出是一份单文件 HTML，支持按主题／时间浏览和搜索。当前先围绕 B 站打磨，已经完成十条视频的样本迭代。

让收藏不止于收藏。

## 完整发布介绍

每次收藏时都觉得“以后会用到”，但收藏夹越来越长，真正回头看的机会越来越少。即使找了 AI 总结，有时也只得到几条标题：知道讲过什么，仍然不知道为什么、怎么做、哪里需要判断。

MarkKiller「收藏夹杀手」想把这一步做深一点。

它会从可取得的完整材料出发，先讲清视频的背景和核心问题，再把实际过程、关键例子、取舍和结果接起来。需要时配一张总图，把原作中的画面放到对应解释旁边；作者的陈述、整理者的解释和未经验证的部分会分开表达。

最终是一份可以保存的单文件 HTML：前面是带封面的内容汇总，支持按主题和时间浏览；进入某一篇，就能看到重点、整体讲解、图文深读、来源定位与适用边界。

首版以 B 站为主，已经用十条独立视频迭代内容和阅读体验。也接受给定图文和导入材料，但其他平台仍需要按实际访问能力验证。它是一套交给 Agent 执行的 Skill，需要宿主提供相应工具；不是一个保证所有网站都能抓取的在线服务。

如果你也有一堆“收藏了但还没读懂”的内容，可以先拿一条视频试试。

项目：https://github.com/PASSIONYOUNGZ/MarkKiller
