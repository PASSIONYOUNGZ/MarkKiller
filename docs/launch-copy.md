# MarkKiller v0.2.0 · 发布文案

## 一句话

从混合收藏里找出你关心的内容，再把视频读成有背景、有过程、有判断的图文笔记。

## 项目介绍

收藏越来越多，真正读进去的却不多。MarkKiller先根据你的主题条件识别和筛选，再核完整材料，把问题、论证、实例与边界串成深度解读。封面帮助认出原作，短总结和关系图帮助进入正文，随文画面与时间定位帮助回查。

这次加入了“只看AI”等语义筛选流程，也把结果放上GitHub Pages。点击就能读，不必先下载HTML。实际收藏样本产出10条独立作品，涵盖开发、科研阅读、职业判断和长访谈；没有把课程分集或外部视频凑进数量。

## 可复制用法

用 $markkiller 检查我的B站收藏夹：[链接]。只解读AI相关内容，最多20条独立作品，不足按实际数量交付。保留原作封面、整体讲解、关键过程与来源。

## 范围说明

识别和深读由宿主Agent结合实际材料完成，不是一个自动抓取所有平台的独立应用。B站优先验证，登录和材料可用性取决于环境。公开发布需明确授权，私人收藏目录和原始字幕不随Skill上传。
