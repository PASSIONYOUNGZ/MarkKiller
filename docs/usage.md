# 使用 MarkKiller

## 先提供对象和范围

给一个视频链接，就解读这一条；给收藏夹链接，再说明先做几条或哪个时间范围。第一次可以从 1—3 条开始，确认效果后接续。指定集合会逐项交代处理结果，不会为了让成品显得更好而悄悄漏掉难处理的材料。

```text
用 $markkiller 处理这个收藏夹：[链接]。
先看最近收藏的 3 条视频；多分 P 课程先列范围，不把整套课程当作一条短片处理。
```

“最近收藏”与“最近发布”不同。你想按哪一种取样，就直接写清楚；成品索引中的时间视图使用作品发布日期。

## 从混合收藏里只看一个主题

```text
用 $markkiller 识别我的收藏夹：[链接]。
只看AI应用开发，排除纯资讯和普通编程，最多20条独立作品。
不足就按实际数量交付；先核正文，再写解读。
```

也可以说“只看科研里的AI工具”“保留有真实过程的案例”。Agent会把自然语言条件写清，核实际收藏条目，记录纳入、排除与待核依据。标题关键词和文件夹名只提供线索，不单独决定入选。

普通数量按目标上限处理，明确要求足额才按exact校验。重复收藏只算一部作品，课程分P不自动拆数，追更合集也不冒充逐条收藏。没有足够材料时给实际数量与已核边界，不用外部视频补齐。低信息量原作可简读，不能靠补充通识伪装深度。

筛选账本留在任务目录的`selection.json`；成品的主题按钮仅用于显示筛选后的阅读结果。开发者可用包内`check_selection.py --input selection.json --reader reader.json`校验两者对应，足额要求加`--require-count`。它检查计数和依据结构，不自动判断主题语义。

## 给定材料也能开始

```text
用 $markkiller 解读附件中的完整字幕和文章。
原视频链接：[链接]。没有核对过的画面请保留限制说明。
```

有现成的同版合格字幕和已审材料时，会优先复用。没有字幕时，Agent 会根据当前环境选择合适的音轨／转写路线；需要理解操作、图表或结果时，再核关键画面。工具与模型不随安装包提供，也不预设你已经登录平台。

## 人工参与只发生在必要位置

读取私密收藏、登录或验证码可能需要本人操作。Agent 应先说明具体平台、入口和影响，不将普通工具故障误报成登录问题。视频需要进入播放器时，由 Agent 静音或暂停。

材料只有标题时只能形成待核索引。拿不到正文或关键画面时，会说明缺口，而不会靠通用知识补成作者原话。

## 阅读方式

先在“内容汇总”看封面、标题和简介。按主题寻找同类问题，按时间回顾发布时间；搜索覆盖标题、作者、正文和图节点，主题与搜索取交集。切换视图会保留筛选。

进入解读后，先看重点，再读整体讲解与总图。图节点可定位具体章节；来源定位帮助回看原片。原作截图可放大，图片原本模糊时放大不会增加可靠细节。

桌面以表格组织索引，手机改为图文卡片。只有明确的展开／收起控件切换正文，选字不会折叠文章。

## 继续与修订

```text
接着上次任务做下一批 3 条，复用已核材料，保存接续记录。
```

```text
优化这份已有阅读版：[HTML 或任务目录]。
保留旧 HTML，重点补足过程解释和图文之间的联系。
```

每轮保留独立 HTML，未变材料不重复采集。研究底稿、审阅和断点留在本地任务目录，公开分享需要另外明确授权。

## 在线阅读，不用先下载

[打开真实AI收藏解读](https://passionyoungz.github.io/MarkKiller/ai-favorites/)可以看到封面索引与单篇页面。若要发布自己的结果：

```text
把这批已完成的解读公开发布到 GitHub Pages：[目标仓库]。
只上传授权的阅读页和公开配图，底稿、私密目录与凭据留本地。
保留本次HTML版本，验证别人点击就能直接阅读。
```

Agent会区分GitHub仓库文件地址与真正的Pages地址，提供首页、索引和单篇链接，并核实际部署和页面加载。默认仍生成可保存的自包含HTML；在线发布是用户授权的交付方式，不是安装Skill后自动公开收藏。

## 运行与输出

生成器使用 Python 3.12+ 标准库。不同宿主的浏览器、媒体工具、音频转写能力和费用由宿主环境决定，Skill 本身不提供这些服务。

单文件 HTML 内嵌 CSS、JavaScript 和引用图片，没有 CDN、字体服务或自动外部资源请求。外部链接只在读者主动打开时使用。受宿主限制而未能执行实际离线打开时，会准确说明验证边界。

本项目曾用开发名 `favorites-distillation`。正式名称为 `markkiller`。若你安装过旧开发版，先把旧目录移到技能扫描目录之外留作备份，再安装新版，避免两个名称同时触发；不要覆盖自己的研究输出。
